Updated 10 October 2026. This is a gap tracker, not an approved national syllabus.

## Official reference
NERDC's 8 September 2025 approved subject offerings notice: https://www.nerdc.org.ng/Doc/NERDC-approved-subjects-notice.pdf (pages 1–2). The subject list is not a source of detailed lesson outcomes. Implementation is phased by three-year education cycle; confirm each school's applicable edition.

## Mandatory evidence per unit
Record class, official subject name, school cohort, curriculum edition, official source URL, page/outcome identifier, mapping rationale, term/sequence, unit version, teacher reviewer/date/decision, required corrections, worksheet and assessment references, accessibility accommodations, supervised pilot status and release gate results. Unknown values must remain 'not established'.

## Release criteria
Verify current class-specific official outcomes; complete original teaching and printable practice; obtain dated independent qualified-teacher approval; run supervised privacy-preserving learner trials; pass accessibility, mobile, cross-level navigation, content and security checks. Do not collect identifiable child data in the evidence register.

## Known blockers
