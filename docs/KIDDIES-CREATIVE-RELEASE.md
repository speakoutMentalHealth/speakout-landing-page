## Optional shape studio

Selected shape lessons offer an original nine-space studio using Circle, Square, Line and Erase tools. A child can select a tool, choose a space, undo a change, clear a design and undo that clearing. Controls have visible labels, accessible names, pressed tool states and keyboard operation. There is no drag-only interaction, timer, best-design judgement or extra reward for a particular arrangement.

The studio retains each supported lesson's design in memory while moving between lessons on this page. Refreshing or navigating away clears it. Designs are not uploaded, stored in browser storage or attached to accounts. Existing exploration stars remain separate and browser-local by account/unit/version. Reaching another lesson, collecting a star or using paper does not require using the studio. Print mode uses the original worksheet/teaching notes and hides interactive controls.

Original inline SVG line examples and labelled action-sequence boxes provide visual practice with equivalent descriptions. PAUSE is a named position in the sequence; the Primary example has three TAP positions in four total positions. The studio practises choices/positions rather than freehand drawing, and digital questions recognise stated examples rather than grade artwork.
