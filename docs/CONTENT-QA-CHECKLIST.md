# Content QA Checklist

- Title is clear.
- Category is correct.
- Audience is correct.
- Description is useful.
- Status is active only if ready.
- No copyrighted material is copied without permission.
- SpeakOut original content is clearly branded.
- External resources are links, not copied text.
- Teacher/parent/student content is age-appropriate.
- Mental health content includes safe support language.
